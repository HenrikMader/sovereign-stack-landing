SovereignStack ships with an offline bundle tarball that contains all container images, package dependencies, and a standalone local Root Certificate Authority (CA) with automatic ECDSA P-384 certificate generation. Once deployed, it requires zero internet connectivity and performs all CVE scanning and secret storage strictly within your local network boundary.
SovereignStack is tested and supported on bare-metal hardware and all major enterprise virtualization platforms:
  • Supported Linux Distros: Ubuntu Server (22.04 / 24.04 LTS), Debian 12 (Bookworm), Rocky Linux 9, AlmaLinux 9, and Red Hat Enterprise Linux (RHEL) 9.
  • Hypervisors: VMware ESXi / vSphere, Proxmox VE, KVM / QEMU, OpenStack, Nutanix AHV, and bare-metal servers (Dell PowerEdge, HPE ProLiant, Supermicro).
Secrets are managed by OpenBao (the open-source, Linux Foundation-governed fork of HashiCorp Vault). The master encryption key is split using Shamir's Secret Sharing (configurable e.g. 3-of-5 key holders). All secrets are encrypted in transit and at rest using AES-256-GCM envelope encryption with mlock memory pinning to prevent swap file leaks.
SovereignStack features atomic updates and automated rollbacks via the native deployment engine. The appliance CLI performs health probe verification before switching traffic. Integrated automated backup scripts take scheduled ZFS snapshots and encrypted backups of Keycloak DB, OpenBao raft storage, and Harbor catalogs with direct export to S3-compatible endpoints (MinIO/Ceph/TrueNAS) or local tape/SAN.
